# Kebijakan Privasi (Privacy Policy) - Monitor Konten

**Terakhir Diperbarui:** 2026

Aplikasi **Monitor Konten** adalah sistem internal untuk kolaborasi tim kreator dalam memantau siklus hidup konten dari tahap ide, penulisan skrip, produksi, hingga jadwal publikasi.

## 1. Data yang Dikumpulkan
Aplikasi ini menggunakan Google OAuth 2.0 untuk autentikasi pengguna. Saat Anda login dengan Akun Google Anda, kami hanya menerima informasi profil dasar publik:
- Nama Lengkap
- Alamat Email
- Foto Profil (Avatar)

Kami **TIDAK PERNAH** meminta izin untuk mengakses data sensitif, pesan Gmail, kata sandi, file Google Drive, atau kontak pribadi Anda.

## 2. Penggunaan Data
Data di atas semata-mata digunakan untuk:
- Mengidentifikasi anggota tim yang sedang aktif di dalam workspace.
- Menampilkan nama dan foto penanggung jawab pada kartu naskah konten dan alur kanban.

## 3. Penyimpanan dan Keamanan Data
Data pengguna disimpan dengan aman pada infrastruktur cloud **Supabase** (PostgreSQL) yang terenkripsi. Kami tidak membagikan atau menjual data Anda kepada pihak ketiga mana pun.

## 4. Penghapusan Data
Pengguna dapat meminta penghapusan akun dan data terkait kapan saja dengan menghubungi administrator tim atau melalui menu logout aplikasi.
